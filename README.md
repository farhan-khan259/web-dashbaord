# EWB Dashboard Frontend

A React dashboard frontend for the EWB Protocol.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## API configuration

Create a `.env` file in `frontend/` with:

```env
VITE_API_BASE_URL=http://localhost:4000
```

## Build

```bash
cd frontend
npm run build
```

## Deploy to Render

Use `frontend/render.yaml` or configure a Render Web Service:
- Build command: `npm install && npm run build`
- Start command: `npm run preview`
